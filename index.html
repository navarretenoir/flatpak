Apps Flatpak de Javiera Navarrete

Repositorio propio (firmado) para instalar con Flatpak: Clima (clima de Chile), Metro Chile (app no oficial), Tu Mundo Pet y Escala de Notas (cálculo de notas escolares en Chile).

flatpak remote-add --user --if-not-exists navarretenoir https://navarretenoir.github.io/flatpak/navarretenoir.flatpakrepo
flatpak install --user navarretenoir io.github.navarretenoir.Clima
flatpak install --user navarretenoir io.github.navarretenoir.MetroChile
flatpak install --user navarretenoir io.github.navarretenoir.TuMundoPet
flatpak install --user navarretenoir io.github.navarretenoir.EscalaNotas

O instala una sola app con su enlace: Clima · Metro Chile · Tu Mundo Pet · Escala de Notas.

English

Self-hosted, signed Flatpak repository: flatpak remote-add --user navarretenoir https://navarretenoir.github.io/flatpak/navarretenoir.flatpakrepo, then flatpak install --user navarretenoir io.github.navarretenoir.Clima (also MetroChile, TuMundoPet, EscalaNotas). Source: github.com/navarretenoir.
